# APSwiftly

APStudy’s official Discord bot for managing a study community, tracking volunteer hours, and keeping contributors connected.

Built for [APStudy](https://apstudy.org), a free AP exam study platform, and also used in Heimler’s Discord server. APSwiftly includes community tools and APStudy’s contributor workflows in one bot!

## Try it in Discord

In a server where APSwiftly is installed (i.e., APStudy or Heimler's Discord Server), run `/help` to see the commands available to you. Try `/ping` to check its connection or `/latex` to turn a math expression into an image.

APStudy’s volunteer and contributor features are only allowed to be used in the APStudy server.

## Features

- **Volunteer-hour tracking:** Look up your own or another volunteer’s hours with `/hours`. Branch managers can add hours, with changes recorded in a log channel.
- **Contributor workflows:** Create contributor channels, send onboarding and follow-up messages, and archive completed channels.
- **Scheduled check-ins:** Set contributor reminders with send-early and cancel buttons (very important).
- **Community management:** Moderate members, configure welcome and leave messages, and logging.
- **Study tools:** Render LaTeX as image attachments, chat through APStudy’s AI integration, and set personal DM reminders.
- **Community activities:** Enable XP and leveling, play mini-games, and use entertainment commands.
- **Interactive configuration:** Manage settings through Discord menus, with help filtered by the commands each member can actually use.
